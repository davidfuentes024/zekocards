# zekocards ゼコカード

A free browser card game for learning **hiragana, katakana and kanji** through
relentless, deliberately un-fun repetition. No account, no payment, no tracking
— everything you do is stored in your own browser.

- Pick the kana columns you want to study.
- Every word, drill and dictionary entry is rebuilt from exactly that selection.
- Answers are typed, or picked from *every* sound you study at once — never
  from four options you can solve by elimination.
- Write your own anchor word on any card; the app quizzes you on your notes.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # static site in build/
```
